## Weather app setup

The weather app uses [OpenWeatherMap](https://openweathermap.org/api). Get a free API key and paste it into `apps/weather/script.js` in place of `YOUR_OPENWEATHERMAP_API_KEY`. Keep your real key out of public commits.

## Run online

Turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main`, folder `/ (root)`) and the homepage will be live at `https://cvcoderm-commits.github.io/html5/`.
