Settings

Higher picks up softer hits. Lower it if talking or other tables get counted.

A ping pong ball "tik" is a high sound, about 2000–6000 Hz. Low sounds such as voices, fans and footsteps fall below the filter.

One hit can echo. Sounds closer than this are treated as a single sound.

When the ball drops, the rally resets and any half-finished count is thrown away. Total keeps going.

    How to use
    1. Put the phone near you, mic facing the table or wall, 1–2 m away.
    2. Pick a mode. Wall Rally = racket + table + wall, so 3 sounds make 1 count.
    3. Tap Calibrate once: stay quiet for 2 seconds, then hit the ball 5 times. Sensitivity and filter set themselves.
    4. Tap Start and play. Each sound fills one orange dot; when all dots fill, the count goes up by 1.
    5. If the count drifts, use +1 / −1. Use Save session to keep it in History.
    6. Mic needs permission. If it fails, open this page over https (for example GitHub Pages) or from Chrome directly.
